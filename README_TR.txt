SIPARIS TAKIP - ANDROID APK PROJESI

Mevcut HTML/PWA uygulamasi Android WebView icinde paketlenir.
Uygulama arayuzu ve siyah-beyaz logo kaynak dosyalardan korunur.

APK derlemesi GitHub Actions ile yapilir:
1. GitHub deposunda Actions sekmesini acin.
2. Android APK olustur is akisinin tamamlanmasini bekleyin.
3. Workflow run sayfasinin en altindaki siparis-takip-apk artifact ZIP dosyasini indirin.
4. ZIP'i acip app-debug.apk dosyasini telefona kurun.

Bu dosya APK'nin kendisi degil, APK derleme projesidir.
